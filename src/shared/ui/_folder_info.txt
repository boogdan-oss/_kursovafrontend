ПАПКА: frontend/src/shared/ui

РОЛЬ У ПРОЄКТІ
Базові UI-компоненти shadcn/ui (стиль new-york, Tailwind v3) і спільні елементи сторінок.
Нові компоненти shadcn: npx shadcn@2.3.0 add <назва> (новіші версії CLI — під Tailwind v4).

ФАЙЛИ
- .gitkeep: Порожній файл, щоб Git зберігав папку.
- badge.tsx: Мітка; варіанти success / warning / danger / info для прибутку і ризику.
- button.tsx: Кнопка.
- card.tsx: Картка.
- dialog.tsx: Модальне вікно.
- input.tsx: Поле вводу.
- page-header.tsx: Заголовок сторінки з описом і кнопками.
- page-placeholder.tsx: Заглушка «Сторінка в розробці» зі списком запланованого.
- select.tsx: Випадний список.
- sheet.tsx: Висувна панель (мобільне меню).
- skeleton.tsx: Сірий блок на час завантаження.
- sonner.tsx: Тости (сповіщення в куті екрана); тема з налаштувань.
- table.tsx: Таблиця.
- tabs.tsx: Вкладки.
- tooltip.tsx: Підказка при наведенні.

Локальна довідка: файл не комітиться (.gitignore).
